# OmniTug 500 — provenance

See [`../PROVENANCE.md`](../PROVENANCE.md) for the full statement covering
every robot under `projects/robots/omnisim/`.

**Summary.** Original work of this repository, Apache-2.0 (© OmniLink). The
visual meshes (`meshes/omnitug500_*.obj`) are built by `meshes/build_meshes.py`
in stock Blender from primitives, bevels and extrusions; no file is imported
into that scene. This package contains no third-party mesh, texture or CAD
file, and nothing in it is imported from or derived from any product model.
